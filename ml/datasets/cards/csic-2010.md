# csic-2010

## Source

HTTP Dataset CSIC 2010, from the Information Security Institute of the Spanish National Research Council. Publisher page: http://www.isi.csic.es/dataset/

## License

LicenseRef-CSIC-2010. The publisher released the set so people could test web-attack protection and did not grant a commercial training license. Commercial use is not established. This registry allows fixtures and eval only. The training entry point must refuse it.

## Size

About 36,000 normal HTTP requests and more than 25,000 anomalous requests, split into three text files: normal traffic for the dataset's own train split, normal traffic for test, and anomalous traffic for test.

## Labels

Each request is normal or anomalous. Anomalous requests were generated to include SQL injection, buffer overflow, information gathering, file disclosure, CRLF injection, cross-site scripting, server-side includes, and parameter tampering.

## Known biases

The requests were generated in 2010 against one Spanish-language e-commerce application, with help from scanner-style tools. The file named for training contains only normal traffic. That name is not permission to train a production model. Attack patterns are old and synthetic, and some parameter values were drawn from real-looking personal records, so generated fixtures stay out of git. The publisher has not published a file checksum; fetch will not keep bytes until a digest is pinned. This card contains no request rows.
